**규칙**
- 이 표의 `상태`가 `검증완료`인 조문만 보고서에 번호를 그대로 쓴다. `[검증필요]`는 보고서에서 "확인 필요"로 표기한다.

## 네트워크 제약 (2026-11-02 기록)

작업 환경(Claude Code 클라우드)의 네트워크 정책에서 law.go.kr, pipc.go.kr, korea.kr, casenote.kr 등 국내 사이트 DNS가 차단되어 원문 대조가 불가했다. 환경 설정 → Network access → Allowed domains에 `www.law.go.kr`, `law.go.kr`, `www.pipc.go.kr`, `www.korea.kr`를 추가하면 일일 루틴이 `검증완료`까지 올릴 수 있다. 허용 전에는 검색 결과(2차)로만 갱신한다.

2026-11-03 재확인: `curl https://www.law.go.kr/` → 000(프록시 CONNECT 403), `curl https://www.pipc.go.kr/` → 000(프록시 CONNECT 403), WebFetch → `getaddrinfo ENOTFOUND www.law.go.kr`. 여전히 차단 상태로 L-01~03 원문 대조 미수행. 같은 날 2차(일일 루틴)에서도 두 사이트 모두 000/CONNECT 403. 2026-11-04·05·06 일일 루틴: 동일(000/CONNECT 403).

**2026-11-06 해소**: 환경 Allowed hosts에 `www.law.go.kr`·`www.pipc.go.kr` 추가 후 law.go.kr 200, pipc.go.kr 메인 400(루트 요청 형식 문제로 추정, 확인 필요). L-01 원문 대조 완료.

## 검증 방법 (일일 루틴용)

1. law.go.kr에서 법령명 검색 → "현행" 탭에서 조문 확인 → 시행일·개정일 기록.
2. 조문 원문을 `references/law/<조문ID>.md`에 복사(출처 URL·확인일 포함).
3. 본 표의 상태를 `검증완료`로 바꾸고 확인일 기입.
4. 체크리스트(`policy-eval-checklist.md`)의 같은 조문 `[검증필요]` 표시를 제거.
