# 개인정보 수집·처리 경로 전수조사 체크리스트

목표: "이 회사에 개인정보가 들어오는 모든 문"과 "나가는 모든 문"을 빠짐없이 적는다.
각 경로는 흐름표(`templates/04_data-flow-table.md`)의 한 행 이상이 된다.

## 1. 수집 경로 (들어오는 문)

| 구분 | 확인 대상 | 확인 방법(비로그인·공개) | 상태 |
|---|---|---|---|
| 온라인 가입 | 회원가입(이메일·휴대폰), 간편가입(소셜 로그인: 카카오·네이버·구글·애플) | 가입 화면 입력란, 동의 체크박스 문구, 소셜 로그인 제공 범위 안내 | |
| 주문·결제 | 비회원 주문, 배송지, 결제 정보, 현금영수증 | 주문서 화면(비로그인 진입 가능 범위) | |
| 문의·상담 | 1:1 문의, 채팅 상담(채널톡·카카오톡 채널), 전화 ARS, 이메일 | 고객센터 페이지, 위젯 스크립트 | |
| 마케팅 유입 | 광고 랜딩 폼, 이벤트 응모, 뉴스레터 구독, 설문 | 랜딩 페이지, 이벤트 페이지 | |
| SNS 유입 | 인스타그램·유튜브·블로그 링크, DM 접수, 댓글 이벤트 | 공식 SNS 프로필·게시물 | |
| 오프라인 | 매장·행사 서면 동의서, 명함, 방명록, CCTV | 매장 안내, 행사 공지, 처리방침의 영상기기 항목 | |
| 채용 | 지원서, 추천 채용, 외부 채용 플랫폼 | 채용 페이지 | |
| 협력사·제휴 | 제휴 서비스 연동 시 전달받는 정보 | 제휴 안내, 처리방침 제3자 항목 | |
| 자동 수집 | 쿠키, 광고 픽셀(메타·구글·네이버), 분석 SDK(GA4·앰플리튜드), 세션 리플레이, 푸시 토큰, 기기 식별자 | 개발자 도구 네트워크 탭(비로그인), 앱스토어 라벨 | |
| B2B | 거래처 담당자 정보, 세금계산서 | 거래 안내 | |

## 2. 처리·보관

| 구분 | 확인 대상 | 상태 |
|---|---|---|
| 저장 위치 | 자체 서버 / IDC / 클라우드(리전) / SaaS | |
| 접근 부서 | CS, 마케팅, 개발, 외주 | |
| 암호화 | 비밀번호·고유식별정보·계좌 등 암호화 고지 여부 | |
| 보유 기간 | 목적별·법령별 기간, 휴면(1년) 처리 방식 | |

## 3. 나가는 문 (제공·위탁·이전)

| 구분 | 확인 대상 | 상태 |
|---|---|---|
| 위탁 | 결제(PG), 배송, 문자·알림톡, 이메일 발송, 고객센터 외주, 클라우드·호스팅, 마케팅 대행, 본인확인 | |
| 재위탁 | 수탁자가 다시 위탁하는지 | |
| 제3자 제공 | 제휴사, 보험사, 광고주, 프랜차이즈 가맹점 | |
| 국외 이전 | 해외 SaaS(메일·CRM·분석·CDN·번역·AI API), 해외 본사 | |
| 법령상 제공 | 수사기관, 과세당국 | |

## 4. 파기

| 구분 | 확인 대상 | 상태 |
|---|---|---|
| 파기 시점 | 탈퇴 즉시 / 목적 달성 / 법정 보존 기간 후 | |
| 파기 방법 | 전자파일 복구 불가 삭제, 서면 파쇄·소각 | |
| 분리 보관 | 법정 보존 정보의 분리 보관 여부 | |

## 5. 공개정보로 알 수 없는 것 → 인터뷰 질문으로 전환

예시:
- 수탁사 계약서에 개인정보 보호 조항·감독 조항이 있는가?
- 개인정보 접속기록을 1년(5만명 이상·고유식별/민감정보·기간통신 시스템은 2년) 이상 보관하고, 내부 관리계획에 정한 주기·방법대로 점검하는가? 점검 기록은? (안전성 확보조치 기준 §8, L-09)
- 휴면 회원 분리 보관을 실제로 하는가?
- 해외 SaaS 사용 시 국외이전 동의 또는 고지를 하는가?

인터뷰 질문은 `cases/<케이스>/interview-questions.md`에 "질문 / 관련 인증기준 / 필요한 증적" 3열로 적는다.
