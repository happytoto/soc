## 3. 항목별 판정표 (3.1 ~ 3.5)

| 기준 | 항목명 | 공개 자료로 확인 가능한 관찰 포인트 | 판정 | 비고 |
|---|---|---|---|---|
| 3.1.1 | 개인정보 수집·이용 | 가입·주문 화면의 동의 문구에 목적·항목·기간·거부권 고지가 있는가, 필수/선택 분리 | | |
| 3.1.2 | 개인정보의 수집 제한 | 선택 항목 미입력 시 가입 가능한가, 과다 수집(주소·생년월일 등) 여부 | | |
| 3.1.3 | 주민등록번호 처리 제한 | 입력란·안내문에 주민번호 수집 흔적, 대체수단(본인확인) 사용 여부 | | |
| 3.1.4 | 민감정보 및 고유식별정보의 처리 제한 | 건강·종교 등 민감정보 수집 화면의 별도 동의, 처리방침 민감정보 항목 | | |
| 3.1.5 | 개인정보 간접수집 | 소셜 로그인·제휴로 받는 항목이 처리방침에 있는가, 간접수집 출처 통지 안내 | | |
| 3.1.6 | 영상정보처리기기 설치·운영 | 매장·사옥 CCTV 운영방침 공개, 처리방침 영상기기 항목 | | |
| 3.1.7 | 마케팅 목적의 개인정보 수집·이용 | 마케팅 동의 별도 체크박스·기본값 해제 여부, 광고성 수신동의 문구 | | |
| 3.2.1 | 개인정보 현황관리 | 처리방침 항목·위탁·제공 목록이 실제 화면과 일치하는가(흐름표 대조) | | |
| 3.2.2 | 개인정보 품질보장 | 회원정보 수정 화면 안내, 정보 변경 시 갱신 경로 | | |
| 3.2.3 | 이용자 단말기 접근 보호 | 앱 권한(카메라·연락처·위치) 고지, 앱스토어 라벨, 권한 거부 시 이용 가능 안내 | | |
| 3.2.4 | 개인정보 목적 외 이용 및 제공 | 처리방침 목적 외 제공 사유 기재, 제휴 혜택 안내와 목적 범위 | | |
| 3.2.5 | 가명정보 처리 | 처리방침 가명정보 항목, 연구·통계 활용 고지 | | |
| 3.3.1 | 개인정보 제3자 제공 | 제공받는 자·목적·항목·기간 4요소 기재, 제공 동의 별도 체크 | | |
| 3.3.2 | 개인정보 처리업무 위탁 | 수탁자 목록이 실제 사용 서비스(PG·배송·알림·CS·클라우드)와 일치, 재위탁 표기 | | |
| 3.3.3 | 영업의 양도 등에 따른 개인정보 이전 | 처리방침에 양도·합병 시 이전 통지 절차 기재(해당 시) | | |
